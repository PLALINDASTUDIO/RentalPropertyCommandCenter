Help & Guide

Understand every main section and use Rental Property Command Center with confidence.

Quick tip:Use Search to find properties, tenants, leases, payments, maintenance notes and documents. Use the theme and Settings controls for appearance, backups and workspace preferences.

Install & Open the App

Phone • Tablet • Computer

Phone

iPhone: open the hosted app link in Safari → Share → Add to Home Screen → Add. Android: open it in Chrome → menu (⋮) → Install app or Add to Home screen.

Tablet

iPad: Safari → Share → Add to Home Screen. Android tablet: Chrome → menu (⋮) → Install app / Add to Home screen.

Computer

Open Rental Property Command Center in Chrome or Edge, then use the install icon in the address bar or browser menu. The standalone Full Version HTML can also be opened directly in a modern browser.

Tip: Open the hosted version online once so offline files can be cached. Use Backup & Restore before clearing browser data or moving your records to another device.

Dashboard

See the most important rental-property information at a glance.

How to use it
  • Review portfolio summary cards, upcoming work, rent status and recent maintenance activity.
  • Use dashboard cards and shortcuts to jump directly to the section you need.
  • Use the dashboard as your daily starting point for the rental portfolio.

Properties

Keep each rental property or unit organized in its own record.

How to use it
  • Add the property name, type, address and practical notes.
  • Create as many records as needed for houses, apartments, condos, duplexes or individual units.
  • Edit a record whenever occupancy, unit details or property notes change.

Tenants

Keep tenant details and lease-start references together.

How to use it
  • Add the lease start date, tenant name and contact or property notes.
  • Use the tenant record to quickly see who occupies each property or unit.
  • Update the entry when a tenant changes, renews or moves out.

Leases

Track lease end dates, monthly rent references and renewal notes.

How to use it
  • Add the property or unit, lease end date, optional rent due time and tenant/rent reference.
  • Use notes for deposits, renewal windows, addenda and other lease details.
  • Review lease records regularly so upcoming renewals are not missed.

Rent & Payments

Track rent amounts, payment status, due dates and payment notes.

How to use it
  • Add the property/unit, rent amount, payment status or frequency and due date.
  • Use notes for payment method, reminders or follow-up details.
  • Review the list to keep paid, due and recurring rent information easy to see.

Tasks & Calendar

Organize rental tasks, due dates, priorities and completed work.

How to use it
  • Add a task, assign an owner or property, choose a due date and set priority.
  • Mark work complete when finished, or reopen it when follow-up is needed.
  • Use this section for inspections, renewals, vendor visits and portfolio reminders.

Maintenance & Inspections

Keep repair, inspection and turnover history clear for every property.

How to use it
  • Add who handled the work, the property/unit, maintenance type and next due date.
  • Record what was completed and what still needs follow-up.
  • Use the latest updates to see recent repairs, inspections, cleaning and turnover work.

Expenses

Track rental operating, repair, turnover and service expenses.

How to use it
  • Add the expense, amount, date and property or payer reference.
  • Use the history to review operating, repair, service and turnover costs over time.
  • Keep descriptions clear so every cost is easy to identify later.

Contacts

Keep tenants, contractors, vendors and service contacts easy to reach.

How to use it
  • Save the contact name, role or service, phone and email.
  • Use it for tenants, plumbers, electricians, cleaners, insurance agents and other providers.
  • Update records whenever contact details or roles change.

Rental Tools

Use three practical tools built for rental handovers, cash-flow checks and turnover planning.

How to use it
  • Move-In / Move-Out Inspection Checklist: review property condition, handover and safety items, then add your own.
  • Rental Income & Expenses Calculator: estimate monthly rental cash flow, costs and reserve needs.
  • Turnover Preparation Planner: calculate a target ready date from the tenant move-out date and planned turnover window.

Documents

Track where important rental documents and references are stored.

How to use it
  • Add the document name, storage location, property/tenant/owner reference and a short note.
  • The app stores a reference to the document, not the actual file itself.
  • Use clear storage descriptions so leases, inspections, policies and invoices are easy to find.

Search & Quick Controls

Find saved information quickly and move around the app without digging through sections.

How to use it
  • Use Search to find saved properties, tenants, leases, rent, maintenance, contacts and documents.
  • Use the theme control to switch between Light and Dark Mode.
  • Use Settings for profile, backup, restore and data controls.
